### Adaptation triggers

> Conditional rules — IF X happens THEN do Y. Let the plan flex without a full re-plan. Tune to the current block. Examples:

- _HIT format grades ❌ twice in a row with a green readiness verdict_ → lower that format's % FTP target by 3 % (calibration rule, `references/ftp-training.md`) — don't touch FTP. With amber/red readiness it's fatigue: fix recovery, keep targets
- _HIT format all ✅, "holding", HR creep ≤ ~5 bpm twice in a row_ → raise that format's target by 2 %
- _SS/threshold sets grade ❌ twice in a row with green readiness_ → check whether FTP is set too high (compare eFTP / recent 20-min power) before cutting watts
- _7-day HRV average below normal range for 5+ days, or RHR +5 bpm for 3+ days_ → cut next week's TSS by ~25 % or bring the recovery week forward
- _Decoupling > 5 % on a qualifying long ride_ → check heat/indoor cooling and carbs/h first. If fueling was < SKILL.md target, add 10–20 g/h next time. If it repeats with clean conditions, add Z2 volume
- _eFTP flat after a full build block_ → first check HIT consistency (< 1/week on average = restore 2/week), then re-run the limiter diagnosis and shift emphasis; consider the CP check if comparable-session power rose while eFTP didn't
- _Weekly TSS misses target by > 15 % two weeks running_ → the plan doesn't fit the athlete's life. Re-plan at a lower ramp rather than chasing the deficit
